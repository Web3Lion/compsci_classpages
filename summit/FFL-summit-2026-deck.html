Press Start: Student Engagement With Gamification

Come see the vision of gamifying the classroom using AI! Student engagement in challenging subjects can include more than just standard lectures! By leveraging AI, educators can create a dynamic, competitive, and highly rewarding environment that turns coursework into something students actively compete over. In this session, we will walk through the evolution of my classroom gamification—starting from a simple, AI-generated Jeopardy game to a fully integrated ecosystem featuring capture-the-flag (CTF) challenges, XP points, daily streaks, and digital badges. You will see a live demonstration of a classroom leaderboard with rank changes that keep students hooked and motivated. Beyond the WOW factor, this session offers a transparent, honest conversation about the journey. We will pull back the curtain on where this project started, the iterations it went through, the technical hurdles overcome, and exactly what it takes for an educator to implement a system like this today.

Session Outcomes
01

Identify AI-Driven Gamification Mechanics

Understand how to use AI to generate and manage game elements like CTF challenges, XP systems, and badge requirements.

02

Visualize the Student Experience

See exactly how live leaderboards, streaks, and rank animations shift student behavior from passive learning to active competition.

03

Evaluate Implementation Feasibility

Gain a realistic understanding of the time, tools, and effort required to build and maintain a gamified classroom, avoiding common pitfalls.

RememberDatabases

Supabase or Neon?

Both are PostgreSQL databases. The difference is how much comes built in.

Database + everything around it · what I use

Supabase

  • Google sign-in, file storage, and live updates built in.
  • Row-level security lets the web page talk to the database safely.
  • A friendly dashboard for viewing and editing tables.
  • Free projects pause after a week with no activity.
CHOOSE IT WHENstudents sign in and you don't want to run a server. This course site uses it.
Just the database

Neon

  • Serverless Postgres that scales to zero when nobody's using it.
  • Branching: copy the whole database to test a change safely.
  • No built-in sign-in. You bring your own server code.
CHOOSE IT WHENyou already have an app or server and only need a place to store data.
Zero server code

The web page talks straight to the database

With Supabase I never wrote or hosted a backend. A few lines of JavaScript on the page save and load data, and security rules inside the database decide what each student can see or change.

Student safety

Keeping students safe

Accounts

Students sign in with Google, so there are no new passwords. On leaderboards they appear under a hacker handle, not their real name.

Data

Row-level security means each student can read and write only their own records. Teachers see only their own classes.

Answers

Flags are checked against scrambled hashes. The answer key never goes into the public code.

AI deterrents

Challenge pages block pasting and set traps for AI copy-and-paste answers. Looking things up is still allowed.

Budget

What it costs

A classroom can run on free tiers. These are the limits you'll hit first.

Free

  • GitHub Pages
  • Supabase and Neon starter plans
  • Render and Vercel hobby plans

Watch for

  • Free databases pausing when nobody uses them
  • Free servers sleeping between visits
  • Storage and bandwidth caps

Worth paying for

  • An AI plan with higher usage limits
  • An always-on database for class days

Plans change often, so check each provider's pricing page.

Lessons learned

Things I wish I'd known

Start tiny

One page that works beats ten that almost work. Add features once students use the first one.

Write rules down

Every rule I learned the hard way goes into the project notes file, so the AI follows it next time.

Bust the cache

Browsers keep old files. A version number on every file makes students load the new one.

Test as a student

Keep a student test account. Teacher accounts hide the bugs students hit.
