TEACHER GUIDE — MODULE MAP

← practice

Which practice quiz to assign for which unit, and when. This maps to the College Board's standard AP CSP Big Ideas / Units, since that's the structure every AP CSP course shares — swap in your own lesson numbers where they differ.

Each quiz draws 10 random questions from a bank of 12–26 items, so repeat assignments don't repeat questions. Begin Quiz is timed/graded (10 questions, one shot, results screen with the student's name for a screenshot). Open Practice is untimed and ungraded, cycling through the whole bank — good for review before a test, not for a grade.

HOW TO ASSIGN
Link students directly to a quiz, or send them to the Practice hub and let them pick. There's no login and no server-side grade record — students self-report by screenshotting the results screen (their name is shown), so this is built for low-stakes formative practice, not a gradebook-integrated assessment. For higher-stakes checks, use the CTF system instead, which does track XP per student.
