BINARY CONVERSION

← practice

Convert between decimal (base 10) and binary (base 2) using 8-bit place values. Practice as long as you like, then take the 10-question quiz.

DECIMAL → BINARY

45 → 00101101
  1. Find the biggest place value that fits: 32. Put a 1 there. 45 − 32 = 13
  2. 16 doesn't fit in 13, so 0. 8 fits: 1. 13 − 8 = 5
  3. 4 fits: 1. 5 − 4 = 1. 2 doesn't fit: 0. 1 fits: 1.
  4. Fill every other place with 0 → 00101101

BINARY → DECIMAL

10010110 → 150
  1. Write the place values over each bit: 128, 64, 32, 16, 8, 4, 2, 1
  2. Keep only the places with a 1: 128, 16, 4, 2
  3. Add them: 128 + 16 + 4 + 2 = 150
