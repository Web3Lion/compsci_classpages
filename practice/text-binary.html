TEXT ↔ BINARY

← practice

Every character is stored as a number. ASCII covers English letters, digits and symbols in one byte each. Unicode covers every language and emoji, and UTF-8 stores those in 1 to 4 bytes. Practice as long as you like, then take the 15-question quiz (5 from each section). Want to experiment freely? Try the Byte Message simulator.

TEXT → BINARY (ASCII)

K → 01001011
  1. Look up the character in the ASCII table: K = 75
  2. Break 75 into place values: 64 + 8 + 2 + 1
  3. Put a 1 in those places, 0 everywhere else: 01001011
  4. For a word, do each letter and write one byte per letter

BINARY → TEXT (ASCII)

01101000 → h
  1. Add the place values that have a 1: 64 + 32 + 8 = 104
  2. Look up 104 in the ASCII table: h
  3. Capital letters matter. A = 65 and a = 97: the two cases are always 32 apart

UNICODE (UTF-8)

é (233) → 11000011 10101001
  1. Find the character's Unicode code point: é = U+00E9 = 233
  2. Pick the byte count from the table below. 233 is more than 127, so it needs 2 bytes
  3. Write 233 in binary, padded to 11 bits: 00011101001
  4. Fill the x's: 11000011 10101001 → 11000011 10101001
  5. To decode, drop the marker bits and join what's left back into one number
