Notice the result comes out the same way no matter what's inside the box. That's the point of an API: your code only depends on the signature (name, parameters, return type) staying the same. The person who wrote this function could completely rewrite the inside \u2014 swap the algorithm, make it 10x faster \u2014 and every program calling it keeps working without a single change, as long as the promise (inputs in, output out) doesn't change.
