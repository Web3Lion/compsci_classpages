HOW IT WORKS · ABOUT 3 MINUTES TO SET UP
  1. 1
    Click Make my copy. Google saves your own copy of the spreadsheet, script included, to your Drive. The original is view-only.
  2. 2
    Open your copy and wait a few seconds for the 🎯 Jeopardy menu. The first run asks you to authorize the script once: Advanced → Go to project → Allow.
  3. 3
    Fill in the Jeopardy tab: categories in row 1, questions and answers below. Or build the board with the AI prompt below.
  4. 4
    Choose 🎯 Jeopardy → ▶ Run Game, pick a theme, enter team names, and project full-screen.

Edit anytime. The game reads live from the Jeopardy tab, so changing a question takes effect the next time you run it.

More in the sheet. The Instructions tab in your copy covers images, Daily Doubles, themes, and saving scores.

MODULE 04 // REVIEWAI PROMPT

Jeopardy Question Builder

Copy an AI prompt that writes a full board as CSV in the exact layout the Jeopardy tab expects: categories in row 1, then question and answer rows for $100–$500.

GET THE CSV INTO YOUR COPY
  1. 1
    Paste the prompt into Claude, ChatGPT, or Gemini. Copy the CSV it returns and save it as a file ending in .csv.
  2. 2
    In your copy, open the Jeopardy tab and put your cursor in cell C1. Columns A and B hold the game's labels; leave them alone. If the board already has questions, select them from C1 to row 11 and press Delete first so no old columns are left over.
  3. 3
    With C1 still selected, choose File → Import → Upload, pick the CSV, set Import location to Replace data at selected cell and Separator to Comma.
  4. 4
    Read every question before class. AI can get facts wrong.

No file? Paste the CSV into C1, then use Data → Split text to columns.

Why quotes everywhere? The prompt has the AI quote every cell so commas inside a question don't split it into two columns.

Document / Folder Language Translator

        
Translate a whole Drive folder or one file into another language: Docs, Sheets, Slides, Word, Excel, PowerPoint, and PDF. Optional OpenDyslexic font and PDF output.

HOW IT WORKS · ABOUT 2 MINUTES TO SET UP

        
    
      
  1. 1
    Click Make my copy. Google saves your own copy of the spreadsheet, script included, to your Drive.
    2. 
      
  2. 2
    Open the 📟Translate📟 menu and choose Set Up Sheet. The first run asks you to authorize the script once.
    3. 
      
  3. 3
    Paste a folder or file link into B1, pick the language in B2, and set OpenDyslexic (B3) and PDF (B4).

Runs on your account. The script uses Google Translate under your own Google login and expects English source files. A folder becomes a new folder named FolderName_Language; a single file gets a translated copy beside the original.

      
PDFs and fonts. Scanned PDFs are read with OCR, so results depend on scan quality. For OpenDyslexic, install the free font from opendyslexic.org first; those files come out as Word, Excel, or PowerPoint, since school Google accounts often can't show the font.

    

      

    


    

      
      

        
MODULE 06 // CANVASAI PROMPT

        

        
Canvas Page Builder Prompt

        
Copy a ready-made AI prompt that turns your lesson into themed, student-facing step-by-step directions for a Canvas page. Paste it into Claude, ChatGPT, or Gemini along with your lesson text.

        

        
        
        
      

        

        

      

      

        
HOW IT WORKS · ABOUT 5 MINUTES PER PAGE

        
    
      
  1. 1
    Pick your Subject, a Theme, and Colors, or leave any on Ask me and the AI will offer choices first. Then click Copy prompt.
    2. 
      
  2. 2
    Paste it into Claude, ChatGPT, or Gemini. Replace the last line with your lesson directions, links, and instructions, or with your current Canvas page content. To keep its links and embeds, copy it from the page's </> HTML editor.
    3. 
      
  3. 3
    Copy the HTML it writes. In Canvas, edit the page and click the </> HTML editor button under the editor.
    4. 
      
  4. 4
    Paste the HTML, switch back to the normal editor to preview, and Save. Ask the AI for changes if anything looks off.
    5. 
    

    

      
Why inline styles? Canvas removes <style> blocks and CSS classes when you save, so the prompt tells the AI to put every color and spacing rule directly on each element.

      
Your words stay yours. The prompt asks the AI to keep all of your text, links, images, and videos exactly as written, and only add structure and styling.

      
Restyling a page you already built? Copy its embedded HTML, not the text you see on screen. Edit the page, click the </> HTML editor, select all, and copy. That keeps every image, video, and link working.
