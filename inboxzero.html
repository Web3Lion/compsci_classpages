HIDDEN BITS

steganography (LSB) simulator · free play, no XP ← simulators

Hide a secret message inside an image by tweaking the last bit of each pixel's color value — a change too small for the eye to see. Then extract it back out.

Each letter becomes 8 bits. Every pixel's blue value gets its last bit (least significant bit, or LSB) replaced with one message bit — the color barely changes, but the data is recoverable.
