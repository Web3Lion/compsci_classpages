Accent-bordered button with the platform's lift-on-hover / press-down interaction; use it for every action.

```jsx
<Button variant="primary" size="lg" mono>SUBMIT FLAG</Button>
```

- `variant`: `primary` (accent fill, one per view) · `secondary` (default) · `ghost` (quiet, dismiss) · `danger` (destructive; border turns red on hover).
- `size`: `sm` inside tables and dense rows · `md` default · `lg` for hero CTAs.
- `mono` uppercases the voice — pair with ALL-CAPS labels.
