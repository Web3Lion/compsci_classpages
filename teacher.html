This dashboard needs Supabase. To turn it on:

  1. Create a free project at supabase.com.
  2. Run supabase/schema.sql, then supabase/google-auth.sql in the SQL editor.
  3. Enable the Google provider under Authentication → Providers.
  4. Paste your Project URL + anon key into supabase-config.js.
